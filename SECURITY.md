# Security Policy

## Supported Versions

We currently provide security updates for the following versions of the Omni-MDX Core parser (including Node.js and Python bindings):

| Component       | Version | Supported          |
| --------------- | ------- | ------------------ |
| **Core Parser** | 1.x.x   | :white_check_mark: |
| **MDX Next** | 1.x.x   | :white_check_mark: |
| **MDX Python** | 1.x.x   | :white_check_mark: |
| Legacy / Others | < 1.x.x | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability within Omni-MDX, please report it privately. We take all security vulnerabilities seriously and appreciate your help in keeping the ecosystem safe.

You can report a vulnerability by:
1. Using **[GitHub Private Vulnerability Reporting](https://github.com/TOAQ-oss/omni-mdx-core/security/advisories/new)** directly on this repository (Preferred method).
2. Or by sending an email directly to **contact@toaq.fr**.

### What to expect
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will triage the issue and, if confirmed, work on a patch immediately.
- We will keep you updated on the progress and notify you when the patch is released.
- With your permission, we will credit you in the release notes and the security advisory.
